# Cisco Router Configuration — Packet Tracer

## Overview
This project contains an independent Cisco Packet Tracer lab focused on router interface configuration, IPv4 addressing and basic OSPF routing.

## Configuration demonstrated
- Configured a Gigabit Ethernet interface with IPv4 address `192.168.12.1/24`.
- Configured a serial interface with IPv4 address `10.10.10.2/30`.
- Configured OSPF process 1 and added the `192.168.12.0/24` and `10.10.10.0/30` networks to area 0.
- Reviewed interface states and router configuration through the Cisco IOS CLI.

## Tools
- Cisco Packet Tracer
- Cisco IOS command-line interface
- IPv4 addressing and OSPF fundamentals

## Learning outcomes
This lab provided practice with router interface addressing, serial links, routing protocol configuration and interpreting Cisco IOS configuration output.

## Project file
`router config.pkt`

## Scope
This is an independent learning lab. The configuration shown documents the settings on one router; end-to-end connectivity and OSPF neighbour formation have not yet been verified.
